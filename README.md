# The Funniest Office Joke, Judged Head to Head

This is my entry for the make.fun competition "The Funniest Office Joke, Judged Head to Head": a single office joke about IT, passwords, and becoming the company's entire security policy.

Run `python3 main.py` and the joke is written to `/output/entry.txt`.
